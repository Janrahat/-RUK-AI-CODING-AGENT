Ten screens of the RUK AI Android app, rendered from the real Compose sources in the repository — every label, card, tab and colour is taken from the Kotlin code that ships.

Kotlin · Jetpack Compose · Material 3 412 × 915 dp @2× 10 screens Palette from RukColors.kt

HOW THESE WERE MADE

The app is a Jetpack Compose project, so it cannot be screenshotted without an Android device or emulator. Instead each screen was rebuilt as a 412 dp HTML layout using the exact strings, card lists and colour constants from the Kotlin sources, then rendered at 2× device scale with headless Chromium.

Source of truth per screen: HomeScreen.kt, SplashScreen.kt, ChatScreen.kt, ToolsScreen.kt + ToolLibrary.kt, ImageGeneratorScreen.kt, VideoGeneratorScreen.kt, CodeAssistantScreen.kt, PdfAssistantScreen.kt, HistoryScreen.kt, ProfileScreen.kt, plus Routes.kt (bottom tabs) and Color.kt (palette).

These are design mockups, not device captures. Where the reference design and the code disagree, the code wins — for example the dashboard uses a two-column card grid because HomeScreen calls cards.chunked(2), and the profile shows its usage tiles as two rows of two because that is what ProfileScreen composes.
